> 主办方强制要求：核心功能流程录屏 + 系统架构讲解 + AI 算法及优化方式介绍，**需有配音或字幕**。

| 文件 | 说明 |

## 视频规格（按主办方要求）

- **时长**：≤ 5 分钟
- **分辨率**：1920×1080 或更高
- **大小**：≤ 200MB（必要时压制）
- **字幕**：内嵌字幕（不单独 srt）
- **格式**：MP4 (H.264)

## 录制工具

- **录屏**：OBS（Mac 版）或 macOS 自带 QuickTime Player（⌘+Shift+5）
- **字幕**：剪映自动识别字幕，校对错别字
- **配音**：自己录 / 剪映 AI 配音（推荐"晓晓"或"声鸣"）
- **后期剪辑**：剪映（剪辑 / 配音 / 字幕 / 转场一站式）

## 录制前必做

```bash
# 1. 确保 mock 模式（无网也能演）
sed -i '' 's/MOCK_MODE=false/MOCK_MODE=true/' .env

# 2. 启动服务
make run

# 3. 浏览器预热（避免第一次切换有延迟）
open http://localhost:8080/Table-Talker.html
# → 把 7 个对话场景都点过一遍

# 4. 录制环境
# - 浏览器全屏（F11）
# - 关闭 DevTools
# - Tweaks 面板默认收起
# - 关闭其他桌面通知
```
