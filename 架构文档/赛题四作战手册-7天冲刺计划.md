## 一、当前情况关键判断

**好消息**：
- 赛题四明确"不严格考核时效性"——可以放心用 function calling / 多轮 Agent
- 性能权重低，主要看正确性，硬件压力小
- 复用现成框架（LangGraph / LlamaIndex / smolagents）合规且加分

**风险点**（一个人最容易翻车的地方）：
1. **15 个数据集 schema 差异巨大**（试航/销售/人口/气象/交通/HR/零售/电影），如果你的 prompt 不携带 schema，模型几乎不可能猜对字段
2. **多轮追问**很容易翻车——上下文一长，LLM 就忘了上一步用的是哪个数据集、哪一列
3. **隐藏评测集格式与公开评测集一致**，所以你必须严格对齐输入输出格式，否则一上传就 0 分
4. **UI 部署在亚信云内网**——别拖到最后两天才申请资源，先把这条线打通
5. **演示视频 + 配音/字幕**——很多团队最后通宵剪视频，建议提前 2 天

**关键技术选型**（都是为"一个人 7 天能搞定"而选）：

| 层 | 选型 | 理由 |
|---|---|---|
| 前端 | **Streamlit** | 一人开发最快；自带文件上传/下载/Markdown/Plotly 嵌入；2 个页面 1 天搞定 |
| 后端 | **FastAPI** | 类型安全、自带 OpenAPI 文档、跟 Streamlit 解耦方便单独评测 |
| 数据查询 | **pandas + DuckDB** | DuckDB 直接读 CSV，对大文件友好；pandas 用于后处理 |
| 图表 | **Plotly** | 交互式（赛题强调"含交互式图表"）；输出 HTML 可嵌入报告 |
| Agent | **自写 ReAct loop** 或 **LangGraph** | 自写更可控；LangGraph 状态管理强 |
| 沙盒 | `RestrictedPython` 或 `subprocess + resource limit` | 防止 LLM 生成的代码炸内存 |
| 部署 | **Docker Compose** | 一份 `docker-compose.yml` 起 Streamlit + FastAPI + Redis |

### 5.1 Schema 抽取（Day 1 用）

```python
# tools/schema_extractor.py
import pandas as pd
from pathlib import Path
import json

def extract_schema(csv_path: Path, n_samples: int = 5) -> dict:
    df = pd.read_csv(csv_path, nrows=10000)  # 大文件抽样
    schema = {
        "name": csv_path.stem,
        "n_rows_sampled": len(df),
        "columns": []
    }
    for col in df.columns:
        col_info = {
            "name": col,
            "dtype": str(df[col].dtype),
            "null_rate": float(df[col].isna().mean()),
        }
        if pd.api.types.is_numeric_dtype(df[col]):
            col_info.update({
                "min": float(df[col].min()),
                "max": float(df[col].max()),
                "mean": float(df[col].mean()),
            })
        else:
            uniq = df[col].dropna().unique()[:20]
            col_info["sample_values"] = [str(x) for x in uniq]
        schema["columns"].append(col_info)
    schema["head"] = df.head(n_samples).to_dict(orient="records")
    return schema

# 一次性跑完 15 个，缓存到 schemas.json
if __name__ == "__main__":
    schemas = {}
    for p in Path("data").glob("*.csv"):
        schemas[p.stem] = extract_schema(p)
    Path("schemas.json").write_text(json.dumps(schemas, ensure_ascii=False, indent=2))
```

### 5.2 Router（Day 1 用）

```python
# agent/router.py
ROUTER_PROMPT = """你是数据集路由器。用户问题如下：
{question}

可选数据集（共 {n} 个）：
{dataset_descriptions}

请输出 JSON：{"datasets": ["数据集名1", ...], "reason": "..."}
只选最相关的 1~3 个数据集。"""

def route(question: str, schemas: dict) -> list[str]:
    descs = "\n".join(f"- {name}: 列={[c['name'] for c in s['columns'][:8]]}"
                      for name, s in schemas.items())
    resp = call_llm(ROUTER_PROMPT.format(
        question=question, n=len(schemas), dataset_descriptions=descs))
    return json.loads(resp)["datasets"]
```

### 5.4 沙盒执行（Day 2 用）

```python
# tools/sandbox.py
import subprocess, tempfile, json
from pathlib import Path

ALLOWED_IMPORTS = ["pandas", "numpy", "plotly", "duckdb", "datetime", "math", "json"]

def run_in_sandbox(code: str, dataset_name: str, timeout=30):
    wrapper = f"""
import pandas as pd, numpy as np, plotly.express as px, plotly.graph_objects as go, json, sys
df = pd.read_csv("data/{dataset_name}.csv")
result = None
fig = None
{code}
out = {{"result": result if isinstance(result, (dict, list, str, int, float)) else result.to_dict(orient='records')[:1000] if hasattr(result, 'to_dict') else str(result)}}
if fig is not None:
    out["fig_html"] = fig.to_html(include_plotlyjs="cdn", full_html=False)
print(json.dumps(out, ensure_ascii=False, default=str))
"""
    with tempfile.NamedTemporaryFile("w", suffix=".py", delete=False) as f:
        f.write(wrapper)
        tmp = f.name
    proc = subprocess.run(
        ["python", tmp], capture_output=True, text=True,
        timeout=timeout
    )
    return json.loads(proc.stdout) if proc.returncode == 0 else {"error": proc.stderr}
```

### 5.5 批量评测（Day 3 用，强制要求）

```python
# evaluation/run_eval.py
import json, time
from pathlib import Path

def run_batch(eval_file: Path, out_dir: Path):
    results, metrics = [], {"total": 0, "success": 0, "with_chart": 0, "latencies": []}
    for line in eval_file.read_text().splitlines():
        item = json.loads(line)
        t0 = time.time()
        try:
            ans = chat(item["question"], session_id=item.get("session_id"))
            ok = True
        except Exception as e:
            ans = {"error": str(e)}
            ok = False
        results.append({**item, "answer": ans, "latency": time.time() - t0})
        metrics["total"] += 1
        metrics["success"] += int(ok)
        metrics["with_chart"] += int(ok and ans.get("fig_html") is not None)
        metrics["latencies"].append(time.time() - t0)
    metrics["task_completion_rate"] = metrics["success"] / max(metrics["total"], 1)
    metrics["chart_rate"] = metrics["with_chart"] / max(metrics["total"], 1)
    metrics["avg_latency"] = sum(metrics["latencies"]) / max(len(metrics["latencies"]), 1)

    out_dir.mkdir(parents=True, exist_ok=True)
    (out_dir / "results.jsonl").write_text("\n".join(json.dumps(r, ensure_ascii=False) for r in results))
    (out_dir / "metrics.json").write_text(json.dumps(metrics, ensure_ascii=False, indent=2))
    return out_dir
```

## 六、metrics 设计建议（赛题四关键）

主办方原话：「关键指标举例：正确率、拒答率、引用精确度等」——这是通用四题描述。**赛题四**实际跑分应至少含：

| 指标 | 含义 | 计算方法 |
|---|---|---|
| `task_completion_rate` | 任务完成率 | 没报错 + 有答案 / 总问题数 |
| `answer_accuracy` | 答案正确率 | LLM-as-judge 或正则匹配 ground truth（公开评测集会给） |
| `chart_generation_rate` | 图表生成率 | 该出图问题里出了图的比例 |
| `multi_turn_consistency` | 多轮一致性 | 多轮场景里前后矛盾的比例（反向指标） |
| `data_provenance_accuracy` | 数据溯源准确率 | 报告中标注的"数据集+列+SQL"是否对得上 |
| `avg_latency_seconds` | 平均时延 | 不重要但要有 |

⚠️ **先看公开评测集格式**，按它的字段定 ground truth 比对方式。隐藏集格式一致。
